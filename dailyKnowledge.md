## Cron
1. * 3 * * * => This usually means, that run a job every minute past 3 hour -> 3:01 - 3:59, it does not mean to run a job every 3 hour.
2. 0 */3 * * * => Now this means to run a job every 3 hour -> 3 , 6, 9 , ...

- */3 -> Break down is, every 3 hour, if it was place in minutes area then every 3 minutes, if it was placed in month area then every 3 months.
